# Lasso

Open-source reporting for AI tooling usage, cost, limits, and behaviour across an organisation.

Lasso connects to **Cursor** and **Claude** (Claude Code + Cowork), maps people onto **GitHub teams**, and serves a single-container dashboard backed by Postgres. It runs on EKS or Fargate.

> Design in progress. See [`docs/superpowers/specs/2026-10-26-lasso-design.md`](docs/superpowers/specs/2026-10-26-lasso-design.md).

## Status
